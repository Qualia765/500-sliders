# 500 Sliders
- a website with 500 sliders
- sliding one will slide the others
- each slider means a different thing
- the sliders that move predict what you would have answered them despite not yet answering them. lok a ghost. ooh spooky
- it uses a small ML model
    - it calculates 1000 neurons made of 500 values + 500 masks
    - if a value is present it in the value and the mask is 1
    - if a value is not present, the value is the mean and the mask is 0
    - the layers are: 1000 -> 512 -> 128 -> 10 -> 128 -> 500
    - it is trained to determine the values based on a sparse sampling of the input values (where only 2% - 50% of the original values are provided)
- it probably does not need a the bottleneck, but I think it reduces overfitting maybe?
    - I'm not an expert at this stuff completely.
    - This worses pretty good and I don't feel like to continue to iterate on it more for now.
- the dataset is from dataset [here](https://openpsychometrics.org/tests/characters/data/) which is the `means.csv` and `std.csv` and part of `web/feature_names.js`.
- the training stuff is in `/src` the website stuff is in `/web`
- to use the ML stuff, please have [uv](https://docs.astral.sh/uv/) installed and use `uv venv` (obv duh) then you can use a CLI with `uv run src/main.py -h` and it will show u da options
- I have been thinking about making a web toy based on a ML model trained on this dataset for many months and went thru many different iterations. Designing it like this, with all the sliders visible at once I believe is the critical breakthrough that makes this kinda cool. Some unimportant aspects & backend implementation details of this web toy were generated by AI, but I believe that all the parts that make this neat are human made.
